Fix login timeout

Back to board Edit task
Task updated — status changed to "In progress" by Ayesha · just now

Description

Edit

Users are being logged out after 15 minutes of inactivity even when "Remember me" is checked. This was reported by 12 users in production after the v2.4 release.

Steps to reproduce:

  1. Log in with any account and check "Remember me"
  2. Leave the tab open and idle for 15+ minutes
  3. Click any link — you are redirected to /login

Expected: Session persists for 30 days when "Remember me" is checked.

Acceptance criteria: Session cookie max-age is set to 2,592,000 seconds when the flag is true. Regression test added.
